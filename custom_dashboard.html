Захиалга өгөх

Маягтаа бөглөхөд 1 ажлын өдрийн дотор холбогдож, яг үнэ, хугацааг тохирно. Урьдчилгаа 50%, үлдэгдлийг хүлээлгэн өгөхөд төлнө.

  • Өгөгдөл тань нууцлалтай — зөвхөн таны төсөлд ашиглана.
  • Эхлээд үнэгүй туршаарай — Дашбоард үүсгэгч-ээр файлаа шууд дашбоард болгож үзэж болно.

Түгээмэл асуулт

Үнэ яагаад «-с» гэж бичигдсэн бэ?

Эцсийн үнэ хуудасны тоо, эх сурвалжийн тоо, өгөгдлийн цэвэр байдлаас хамаарна. Танилцах дуудлагын дараа яг үнийг бичгээр тохирно.

Өгөгдөл маань эмх цэгцгүй байвал?

Асуудалгүй. Цэвэрлэх, нэгтгэх ажил үнэд багтана. Маш их цэвэрлэгээ шаардлагатай бол урьдчилан хэлнэ.

Power BI лиценз шаардлагатай юу?

Power BI Desktop үнэгүй. Бусадтай онлайнаар хуваалцахад Power BI Pro лиценз хэрэгтэй. Лицензгүй бол HTML дашбоард хямд, хурдан хувилбар болно.

Дараа нь өөрөө засаж болох уу?

Болно. Excel, Power BI файл бүрэн нээлттэй хүлээлгэн өгөгдөнө. Бүтцийн тайлбар, богино видео заавар хамт очно.

Сар бүр шинэчилж өгөх үйлчилгээ байгаа юу?

Тийм. HTML болон Excel дашбоардыг сар бүр шинэ датагаар шинэчилж өгөх захиалга авдаг. Холбогдоорой.
