Нууцлалын бодлого

Ямар мэдээлэл цуглуулдаг, юунд ашигладаг, хэрхэн хамгаалдаг — энгийн үгээр.

Сүүлд шинэчилсэн: 2026-10-09 · Хүчин төгөлдөр: 2026-10-09

1. Хамгийн чухал зарчим

Хэрэгслүүдэд оруулсан файл (НДШ тайлангийн PDF, eBarimt Excel, банкны хуулга, e-balance тайлан) таны хөтөч дотор боловсрогдоно. Ажилтны регистр, цалин, харилцагчийн мэдээлэл BusinessBI-ийн серверт илгээгдэхгүй, хадгалагдахгүй.

2. Бид юу цуглуулдаг вэ

  • Бүртгэлийн мэдээлэл — имэйл, нэр (Google-ээр нэвтэрвэл Google-ийн өгсөн нэр, зураг). Firebase Authentication / Supabase Auth ашиглана.
  • Үйлдлийн лог — аль хэрэгслийг хэзээ ашигласан, файл татсан эсэх, хөтчийн төрөл. Үйлчилгээг сайжруулах, алдаа олоход ашиглана.
  • Төлбөрийн бүртгэл — хэрэгсэл, тайлант үе, дүн, төлбөрийн төлөв, WIRE.mn-ийн гүйлгээний дугаар. Карт, дансны мэдээлэл бидэнд ирэхгүй — WIRE.mn-д хадгалагдана.
  • Холбоо барих хүсэлт — нэр, утас, имэйл, мессеж. Зөвхөн тантай холбогдоход ашиглана.
  • Санхүүгийн програмын cloud нөөцлөлт — та идэвхжүүлсэн тохиолдолд журнал, данс, харилцагчийн өгөгдөл таны бүртгэлтэй холбоотойгоор Supabase (өгөгдлийн сан) дээр хадгалагдана. Идэвхжүүлээгүй бол зөвхөн таны төхөөрөмжийн хөтөчид хадгалагдана.
  • Нягтлангийн профайл — нягтлан болж бүртгүүлсэн хүний нэр, зураг, туршлага, үнэ, холбоо барих мэдээлэл олон нийтэд харагдана (таны зөвшөөрлөөр).

3. Юунд ашигладаг вэ

  • Үйлчилгээг үзүүлэх, төлбөрийг баталгаажуулах, файл татах эрх олгох
  • Алдаа засах, үйлчилгээг сайжруулах
  • Таны хүсэлтэд хариулах, чухал өөрчлөлтийг мэдэгдэх

Мэдээллийг зар сурталчилгааны зорилгоор гуравдагч этгээдэд зарахгүй, дамжуулахгүй.

4. Гуравдагч үйлчилгээ

  • Google Firebase (нэвтрэлт, өгөгдлийн сан, серверийн функц)
  • Supabase (санхүүгийн програмын cloud нөөцлөлт, нягтлангийн платформ)
  • WIRE.mn (төлбөрийн гарц)
  • Google Fonts, CDN (үсгийн фонт, нээлттэй эхийн сан)

5. Хадгалах хугацаа, устгах

Бүртгэлийн мэдээллийг та бүртгэлээ устгах хүртэл; төлбөрийн бүртгэлийг нягтлан бодох бүртгэлийн хуулийн дагуу шаардлагатай хугацаанд хадгална. Бүртгэл, өгөгдлөө устгуулах хүсэлтийг hello@businessbi.mn руу илгээхэд 5 ажлын өдрийн дотор биелүүлнэ.

6. Cookie, хөтчийн санах ой

Нэвтрэлтийн төлөв, хэрэгслүүдийн тохиргоо (ж: ТТД толь, төлбөрийн тасалбар) таны хөтчийн localStorage-д хадгалагдана. Хөтчийн өгөгдлөө цэвэрлэвэл эдгээр устна.

7. Аюулгүй байдал

Холболт HTTPS-ээр шифрлэгдэнэ. Өгөгдлийн санд хандах эрхийг дүрмээр (security rules) хязгаарласан: хэрэглэгч зөвхөн өөрийн бичлэгийг уншина, төлбөрийн бичлэгийг зөвхөн сервер үүсгэнэ.

8. Холбоо барих

Нууцлалтай холбоотой асуулт: hello@businessbi.mn
